# Pickyeaterr Studio Bridge

pickyeaterr.com 的 WordPress 橋接外掛，讓 Pickyeaterr Studio 能安全地更新文章的 SEO 欄位、GEO／AEO 區塊、網站樣式、速度優化與廣告版位設定。

- 這個儲存庫只放外掛本身，不含任何密碼或金鑰。
- WordPress 會從這裡的 `main` 分支檢查新版本（v2.3 起），在「外掛」頁出現「立即更新」，也可以開啟「自動更新」。
- 程式由 Pickyeaterr Studio 的 `wp-plugin/pickyeaterr-bridge/` 同步過來，請不要直接在這裡修改。
